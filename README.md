Twin Worlds — a spot the difference game: five hand-drawn worlds (a forest camp at dusk, a cozy bakery, a coral reef, a mountain railway, a night market), seven hidden differences in each, hints, a draining clock, strikes, combo scoring and stars.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click a difference in either picture, H for a hint, P to pause.
